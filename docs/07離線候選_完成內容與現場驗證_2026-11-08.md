# 07 離線候選：完成內容與後續驗證

> 2026-11-09 更新：三套實車適配候選、起點與暫停回正接續已完成本輪離線開發；見 [最新交接](07離線適配_起點與回正接續_2026-11-09.md)。下文保留為 11-08 歷史，未部署狀態仍相同。

入口：工作台 07 →「進入離線流程測試」。版本 `.608`。

## 已實作並離線測試

- 固定方案直接取 Claude 三包，準備時凍結快照；接續若換包會拒絕。
- 紅綠燈：先 0 後 1、初始 1 不放行、一次性；取消或故障後不放行；訊號未知清除已見紅燈狀態。嚴格 HTTP 讀取器只認 0／1，timeout 0.2 秒；本機假 HTTP 測試通過。假流程只在等待時輪詢，50 ms 最小間隔，不重疊請求。
- 無限時候選：沒有 deadline，假執行器獨立於瀏覽器；假時鐘連續 24 小時仍運行。相機、路徑、UART、I²C、急停任一假故障停止假輸出；排除故障不自動繼續。
- 場次：同一場串接多個片段，保存固定方案、有效運行時間、位置、事件、圈資料；暫停凍結有效行駛時間，手動接續；重置前須停止，歷史另存。
- 接續候選：支援既定九個語意入口、第一輪／下坡後階段；同地接續保留假里程，搬車重設指定入口並標當圈不完整。控制板假重啟或筆電程序重啟後不得自動出發。
- 假小地圖與假過旗計時：使用同一份 01–12 底圖、假里程 1 m/s；完整圈與人工移位的不完整圈分開。這不是實車定位、真實起點偵測或圈時計算驗收。
- 記錄寫入失敗時先關閉假輸出；起跑意圖先保存，再放行。

測試：`python -m unittest test_ops07_candidate test_ops07 -v`（在 laptop_workbench 目錄執行），25 項通過。另有實際 localhost HTTP 假旗標測試，以及瀏覽器操作初始綠燈、紅轉綠、暫停、搬到坡頂接續、I²C 假故障停止。資料在 `data/experiments/ops07-offline-20261108/acceptance.json`。

## 實作邊界：還有程式接入工作，不只是等待現場驗收

`ops07_candidate.py` 是可執行的候選狀態機，執行器固定為 **FakeExecutor**，沒有硬體或 SSH 呼叫。正式頁開始／接續仍停用，離線頁的按鈕只送本機 `lab-*` API。

尚未修改 Orin 的 `live_pid.py`／`manual_drive.py`，也尚未把語意接續計畫轉成真正 CurveMap、DashRoute、交叉窗口、航向／里程歷史的重建程式。因此不能直接把 FakeExecutor 換成馬達函式就部署。

上車前仍須依最新車端原檔完成：

1. 真實執行器的 prepare／release／stop 與 ACK 不明處理；準備階段是否回正須明確界定。
2. 兩層車控的 deadline 均移除於新模式，保留原模式及既有影像年齡、丟線、UART、故障與急停保護。24 小時假測試不證明現役兩層程式已無限時。
3. 真正控制器的原地檢查點保存與入口重建，包含 generation、第一輪／下坡後、路口前後，不能只恢復畫在地圖上的位置。
4. 在 Orin 背景工作中接 HTTP 讀取器與綠燈狀態機；本次 UI 假旗標為記憶體來源，實際讀取器另經本機 HTTP 驗證。
5. 方案備份、啟用與實際載入值讀回；長時間記錄輪替與空間耗盡策略。候選目前使用 SQLite 快照歷史，尚非長跑記錄儲存最佳化。

這些都未部署。本次只重載筆電工作台，沒有操作 Orin、控制板、馬達或舵機。

## 需要現場的驗證

| 項目 | 要確認的結果 |
| --- | --- |
| 場地網路 | Orin 與 Pi 同網段、確認裁判最終 IP、/go 與正式／練習模式；未假定文件 DHCP IP 永久有效 |
| 綠燈實際放行 | 準備完成再等燈、紅燈期間雙輪無動力、初始綠燈不跑、0→1 僅一次、等待期間取消與急停有效 |
| 無期限行駛 | 真實兩層車控沒有舊期限；瀏覽器離頁、關閉或 Wi-Fi 斷線不停止新自主模式；故障保護仍能停止 |
| 暫停／接續 | 原地、搬車、控制板重啟分開驗；先做直線與指定入口，再逐段驗路口、上坡、坡頂；不宣稱彎中／下坡中直接接續 |
| 停止行為 | 停止 ACK、雙輪輸出與實體滑行分別核對，保留現場實體停止 |
| 定位與圈時 | 核對 01–12 路段、重疊交叉的分支、旗子位置及過線事件；搬車／重連不補圈或重複圈 |
| 記錄 | 長跑效能、磁碟空間、斷電最後保存點與部分紀錄恢復 |

前車停等仍缺偵測模型與有效距離來源，約 3 m 只是需求；本次沒有用假車距冒充這項功能完成。
