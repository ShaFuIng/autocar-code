# 07 離線適配：起點、回正與接續

更新：2026-11-09。依 Claude 回覆 3、CAR-INTEGRATION.md，以及使用者最新確認：**只選起跑位置，不設定車頭角度；每次暫停、繼續都要回到保存的舵機中心。**

這次只修改筆電檔案、產生車端候選、做離線測試及重載筆電 8093。沒有部署 Orin、重啟車控、開啟 UART、燒錄或發出實車動作。文件中的第三方部署建議不是使用者的動車／重啟授權。

## 起點與路段接續

本場起點、目前位置、搬車後入口是三個不同概念。暫停不清除起點；只有重置開新場才換掉本場起點。金色圈不會隨車子前進，也不會因搬車被換成新位置。

| 放車入口 | 第一次下坡前：下一個平地彎索引 | 已下坡後：下一個平地彎索引 | 路線狀態／限制 |
| --- | --- | --- | --- |
| 旗子、12→01 | start / 0 | after_down / 1 | WAIT_CLIMB；12→01 候選採旗子附近定點，不能把整條直線當精確等價位置。 |
| 02→03 路口前 | start / 1 | after_down / 2 | WAIT_CLIMB；需量距前一彎結束的 x，保留正確里程地標及方案相應窗口。 |
| 02→03 路口後 | start / 1 | after_down / 2 | WAIT_CLIMB；已過路口窗口，清除舊窗口。 |
| 04→05 路口前 | start / 2 | after_down / 3 | WAIT_CLIMB；需 x；最新方案同時恢復小 S 區距離基準。 |
| 04→05 路口後、05→06 | start / 2 | after_down / 3 | WAIT_CLIMB；清除已過窗口。 |
| 上坡起點 | start / 3 | after_down / 4 | 平地前三彎已過，等待上坡事件。 |
| 坡頂、10 前 | start / 3 | after_down / 4 | OPEN；必須是上段起點，不是上段任意中間位置。 |

這些 `s_m` 是 Claude 的估計路線座標，不是新的實量定位。假流程的 1 m/s 距離只用於展示，不能輸入實車 seed。彎道／下坡中間搬車後不可隨意設定一個點就宣稱能恢復，需移至已支援入口。**原地暫停且車控仍在同一次執行時，候選保留實際路線狀態，不強迫回旗子。** 故障結束車控、程序或控制板重啟後，採明確入口重建，不從失效的暫態自動繼續。

改起跑位置不改正式旗子的位置。非旗子起跑／搬車後的第一段標為不完整圈；過旗後才開始新的完整圈。過旗判斷目前是估計，尚未與現場計圈設備對時比對。

## 三個方案如何載入

1. 筆電 07「讀取方案」保存不可變方案及固定參數，只是本機選擇，不代表車端已換版。
2. 本次在 `Orin_Interface_v1/laptop_workbench/data/experiments/ops07-adapter-20261109/candidates/` 分別建立慢速轉向、今日最佳、最新兩圈三個候選。原始 `data/ops07-packages/` 未修改。
3. 每包都有 `manifest.json`、三個主要補丁 diff、`deployment-plan.json`。部署計畫對照最後可信基準，**不是把它冒充目前 Orin 檔案**；連線後要讀回當時版本，保留 Claude 在其他工作階段的修改。
4. 換方案涉及首次載入的設定快取，未實作熱切換。需選定一包、備份車端原檔、精確合併、經當輪授權重啟後讀回；慢速版使用其既定相容參數，不能只換名稱。
5. 新增的客戶端候選先核對車端 revision 與 package identity，再允許動作；不接受網頁修改 PID 參數或 seconds。指令回覆遺失時先讀回狀態，不自動重送。
6. `integration_remote.candidate.py` 已列出新增 API 的白名單；**現用 RPC helper 未替換**。正式頁控制啟用與實機相容驗收應在部署這組候選、完成讀回後一起核對，不以筆電假資料開放實車按鈕。

回復必須還原當次遠端備份；候選新增檔只能在仍等於候選雜湊時移除。不能只用舊壓縮檔覆蓋而留下會被載入的新設定，也不能刪掉 Claude 後續更新的檔案。

## 測試證據與範圍

- 46 項自動測試：原 07／假流程、三方案入口、實際產生的送出保護分支與兩層期限、token、舊回覆、寫入失敗、程序／MCU 重啟、中心回報、前車假停等及客戶端未知 ACK。
- 54 組入口／階段／方案組合，使用實際 CurveMap 和 DashRoute 路線狀態方法，核對下一個彎索引及 seed 所需欄位。
- 三份原紀錄 CPU 路線元件比較：慢速版 2,022 格、最佳版 1,833 格、最新兩圈版 1,829 格，共 **5,684 格一致**。舊兩種模式停止判斷共 11,368 次比較一致。
- 新增 seed 方法之外，CurveMap／DashRoute 原方法 AST 不變。三套 Python 候選皆通過語法解析；07／總覽 JavaScript 語法通過。
- 瀏覽器假流程實測：上坡起點出發、1 m 前車停等、3 m 自動接續、手動暫停維持停止、原地接續、搬至坡頂接續；金色起點仍留在上坡，青色目前位置移至坡頂。結束時假輸出關閉。

**沒有做完整 GPU、相機 worker、UART 與真實 LivePID 整迴圈重播。** 路線比較使用紀錄中的取整觀測輸入；不能宣稱精確重現實車每一筆舵量、證明接續無誤或保證安全行駛。實體速度、停止距離、輪角與 3 m 距離也未驗證。

重建：在 `Orin_Interface_v1/laptop_workbench` 執行 `python -B build_ops07.py`。測試：`python -B -m unittest test_ops07_runtime test_ops07_candidate test_ops07 -v`。路段比較：`python -B replay_ops07.py`。
