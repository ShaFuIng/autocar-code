## 2. YOLO26 與語意分割的釐清

- **單一模型 YOLO26n-sem，任務為語意分割**。專案沒有部署物件偵測或實例分割。

## 4. 版面與內容建議

1. **比例**：四區塊合理。建議標題 12%、車體 35%、過渡句 8%、AI 40%。AI 區塊真實成果最多，應最大。
2. **車體區塊**：一張大照片，周圍 6–7 個標示（Orin、相機、舵機與連桿、PCA9685、BMduino、後輪馬達與編碼器、IMU），旁放一條小架構圖：
   `相機 → Orin（YOLO26 分割、路徑、PID、IMU）→ UART → BMduino → 舵機／馬達`
3. **AI 區塊**：上排三格「原始畫面 → 白線遮罩 → 規劃路徑」（同一畫面）；下排左側實車試跑 3–4 格連續畫面（直線、彎道、上坡），右側 4 個數據方塊：模型名稱、類別數、Orin 推論 26 ms、邊界 IoU 0.86（附測試條件）。
4. **避免的說法**：「自動駕駛」「完成全程」「物件偵測」「四輪驅動」「Arduino UNO」「TensorRT 加速」「SLAM／地圖定位」「準確率 99%」「30 FPS 即時控制」。
5. **標題建議**：「AI 視覺循線自走車：從影像分割到車體控制」。
   **過渡句**：「以車載相機取得賽道影像，於 Jetson Orin Nano 執行 YOLO26 語意分割辨識白線，推算行駛方向後經 UART 控制轉向與動力；目前已在實際賽道進行閉迴路試跑。」
