直行校準

正值＝W 前進方向，負值＝反轉；S 會把兩輪一起反向。可以一輪正轉、一輪反轉（需韌體 mixed_direction_version 1；舊韌體會回 MIXED_DIRECTION）。行駛中改變某一輪的正反向會被拒絕，請先停車；韌體也要求該輪停 0.5 秒才換向。

0 秒表示直接設定 PWM（保留韌體毫秒級漸增）；大於 0 的時間表示 PWM 從零升至設定上限、或從設定上限降至零的時間，不是實際車速或煞停時間。

數值越大，按住 A／D 轉向及按 C 回中心越快。建議先用 300；可在 50～800 間調整。這是指令變化速度，並非實測轉角；左右行程仍受限位保護。

直接輸入為草稿；按套用本次或保存後生效。

保存中心為 Orin 共用值：03 校準、04 手動啟用／回中心及後續使用共用設定的操作都會使用。手動運行中先套用本次，結束後 BMduino 同步保存版本。保存不會主動送回中心指令。開機最初的 1360 µs 回正仍是韌體固定值；02 純模擬資料獨立保存。

設定保存紀錄

微調即時套用；放開油門後會持續減速一段時間，空白鍵立即歸零。中心逐步調整，行駛中單次中心變更最多 20 µs。限位沿用操作台設定。

鍵盤／按住按鈕操作

W 前進　S 後退　A 左轉　D 右轉　＋／－ 同步微調兩輪動力　C 轉向回中心　空白 動力立即歸零　Esc 停止鎖定

先點擊相機畫面，看到綠色外框後使用 WASD 或 ↑↓←→；點擊區外，動力歸零並退出鍵盤駕駛。可在右側微調後再點入畫面，不需重新實體啟動。

放開 W／S 依設定時間降低動力；放開 A／D 保持轉向，C 逐步回中心。A／D 同時按住以最後按下者優先；W／S 同時按住減速，換向先停輪。空白鍵及點擊操作區外立即將動力歸零。輸入數字時不接受駕駛按鍵。切分頁、視窗失焦、相機或通訊失聯會停止鎖定，回來不自動恢復。PWM 歸零不等於已驗證的煞車。
