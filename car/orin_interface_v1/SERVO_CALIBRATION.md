# 舵機中心與限位設定（orin-v1.2.0-cal）

使用者已確認舵機為180°定位型、連桿已安裝。暫定前輪回正中心1460 µs；測得左約960、右約1860，但機構有延遲／間隙，尚未精確校準。第一版先以1010～1810 µs留餘量，不代表已驗證安全端點。

## 使用網頁

http://10.155.149.240:8000/ ，登入不變，Ctrl+F5更新。

- 左限位、中心、右限位可直接輸入；必須左值 < 中心 < 右值。
- 「保存設定（不移動）」只存檔並同步，不轉動舵機。若輸出已啟用，新的限位不得排除目前指令位置；回中心途中也不能保存。
- 「保存目前位置為中心」將目前的脈寬設定存為中心，不移動；需要自行觀察前輪確已回正。
- 「啟用並定位至中心」：放開急停、按一下實體啟動鍵後，明確點此鈕才首次啟用。關閉狀態下無實際角度回傳，因此第一次會直接輸出保存的中心，可能轉動；不是從未知位置平滑移動。
- 已啟用時可按「逐步回到中心」；BMduino每120 ms改10 µs，期間小步按鈕停用，關閉或急停可中斷。到達中心表示指令到達，非前輪感測到達。
- 保留5／10／20 µs手動步長，預設10。圓盤為相對中心的指令比例，非真實前輪角度。

## 保存與同步

設定存在 Orin `~/.config/orin_car/servo_profile.json`，原子寫入，包含revision/min_us/center_us/max_us。不用為每次改中心重燒。同步成功前不接受舵機移動；UI會顯示保存版本與同步狀態。

BMduino接收PROFILE後在RAM中保存，所有SERVO命令（包括USB小步）都由韌體限位。Orin服務重啟、BMduino重開機後重新SYNC與PROFILE；只同步設定，沒有自動定位或解鎖。設定檔損壞／不同步時保持禁止動作，不默默使用舊預設。

首次需燒錄一次orin-v1.2.0-cal，因舊版無PROFILE／CENTER命令。之後中心／限位修改都由Orin同步。急停、STOP、故障仍停用脈波並鎖定；舵機校準不會啟動馬達；專用TEST模式才允許定時測試兩顆後輪。READY保持，不因閒置逾時。

UART協議：`SEQ,PROFILE,generation,revision,min_us,center_us,max_us`；`SEQ,CENTER,generation`；原SERVO仍用CRC、序號與generation。手動单步最多100 µs、至少100 ms、PCA9685有效計數器。CONFIG不寫BMduino EEPROM；Orin檔案是持久來源。

輸出關閉不保證舵機斷電／釋放力，前輪不跟隨的原因仍需檢查齒輪／連桿間隙、摩擦和結構彈性。不要把指令脈寬直接當實際輪角。
