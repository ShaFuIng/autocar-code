3. **校準與性能測試**：A～K用途、工具、位置示意、步驟、單位、逐欄資料來源、參考點、條件、草稿／重測／採用。C、F、H、K提供有限的算式估計。照片及影片可晚補；J可在附件照片上點選原圖像素、保存對應地面點。
4. **手動與場地測試**：固定動力、合成模型、遙控輸入、純錄影事件四種互斥模擬模式；網頁授權、有限時間、明確停止、急停、故障、視覺失效、執行器重啟與離線實驗。
5. **錄影與回放**：既有影子原圖／遮罩／A或B路徑；既有直線影片影格與控制事件；合成任務事件。依 `capture_s` 或原始ISO時間戳播放，區間評語另存版本。可匯出JSON及上傳附件／人工對時。
6. **模型與算法比較**：基準／候選、固定資料版本、拆分方式、人工評分與限制保存；連到同影格回看。

「已採用」只代表使用者採用一筆人工紀錄，**不代表自動寫入車輛配置或完成物理驗證**。沒有數值的欄位是 `null`，不是0。估計方法及限制顯示於測試卡。手機僅為照片／場地旁外部影片工具，沒有手機或藍牙控制功能。

## 建議驗收路徑

- 配置中留空軸距，保存、重新整理；空白應保留，模擬動力仍為0。
- 測試A留空保存，切到其他卡後回來；草稿可續做。
- 開兩個配置頁，在第一頁保存後用第二頁舊版本保存，應顯示409衝突、保留未同步草稿。可先看版本紀錄比較，再連按兩次「恢復保存值」捨棄本機草稿。沒有自動合併或覆蓋。
- 開啟模擬授權，固定動力10秒；按「開始並模擬ACK遺失」，等超過10秒後重連，應查回同一ID與 `DURATION_COMPLETE`。期間停止按鈕應說明請求無法送達。
- 遙控模式若沒有新輸入，0.75秒後停止；剛接受時維持模擬0動力。固定任務不受路徑失效影響，視覺任務相機／路徑失效即停。
- 任務中急停／故障後解除不續跑；重啟模擬執行器後授權關閉、上限回25%。保存配置仍保留，必須重新明確套用。
- 預覽關閉時，任務事件仍由後端記錄，頁面不持續請求圖片。低頻預覽只是既有圖片，不是推論效能測試。
